예약 가능한 시간은 빠르게 확인하고, 취소/변경은 정책에 맞게 처리합니다.

학생은 월간 캘린더에서 즉시 예약하고, 선생님은 주간 시간표와 예외일정을 분리 관리할 수 있습니다. API 상태는 하단 로그에서 실시간으로 추적됩니다.

월간 탐색 + Today 이동 예약 가능/불가 즉시 구분 역할별 화면 자동 전환 취소 컷오프 정책 반영

인증 및 세션

교사/학생 계정으로 로그인하면 해당 화면만 노출됩니다.

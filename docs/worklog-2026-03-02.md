## 추가 작업 (블럭 예약/예외/초대/공휴일)
- 예약 단위 변경
  - 고정 수업길이 기반 분할 대신, 교사가 만든 슬롯 블럭 자체를 예약 단위로 사용
  - `09:15~10:15`, `10:30~11:00` 같은 비정시각/가변 길이 블럭도 학생 화면에서 그대로 노출/예약됨
- 1회성 수업 오픈 구조 개선
  - 단일 생성(`repeat_mode=single`)은 예외 대량 생성이 아닌 `one_time_availabilities`에 1건 저장
  - 신규 마이그레이션: `006_one_time_availabilities.sql`
  - API 추가:
    - `GET /api/v1/teachers/me/one-time-availability`
    - `POST /api/v1/teachers/me/one-time-availability`
    - `DELETE /api/v1/teachers/me/one-time-availability/:id`
- 예외 처리 단순화
  - 예외 등록을 블럭 단위(시작/종료 필수)로 강제
  - 예외 겹침/충돌 검증 유지, 캘린더에서 해당 블럭만 차단
- 학생 초대 기능
  - 교사 화면에 `학생 초대 링크 복사` 버튼 추가
  - 링크 형식: `/student-calendar.html?teacher=<teacherId>`
  - 학생이 링크로 접속하면 해당 교사가 기본 선택됨
- 한국 공휴일 표시
  - KR 공휴일 데이터를 연도 캐시로 로드해 학생/교사 캘린더 헤더와 셀에 표시
- 페이지 동기화
  - `teacher.html` 변경사항을 분할 페이지(`teacher-*`, `student-*`)에 동기화
